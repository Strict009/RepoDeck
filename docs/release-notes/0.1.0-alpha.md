RepoDeck makes it easier to actually use the free software on GitHub, even if you have never
used Git and have no idea what a repository or a release is.

**This is the first build anyone other than its author can install.** It is an alpha. It
works, it has been tested, and it is not finished.

## Which download do I want?

| | |
|---|---|
| **RepoDeck-Setup-0.1.0-alpha-win-x64.exe** | The normal one. Installs RepoDeck and puts it in your Start Menu. |
| **RepoDeck-Portable-0.1.0-alpha-win-x64.zip** | Unzip it anywhere and run `RepoDeck.exe`. Nothing is installed. |

Windows 10 or 11, 64-bit. You do **not** need to install .NET or anything else first — the
runtime is included.

## Windows will warn you, and it is right to

Both downloads are unsigned, so Windows SmartScreen will show **"Windows protected your PC"**
with a *Don't run* button.

That warning is not a judgement about RepoDeck. It means Windows has never seen this file
before and nobody has paid for a code signing certificate to vouch for it. You will see the
same warning from most small open-source projects.

If you want to run it anyway, click **More info**, then **Run anyway**. If that makes you
uncomfortable, that is a completely reasonable instinct — check the checksum below first, or
wait for a signed build.

## Where RepoDeck puts things

**The program** goes in `%LOCALAPPDATA%\Programs\RepoDeck`. It installs for your user account
only. It does not ask for administrator access and does not need it.

**Everything else** — applications RepoDeck installs for you, your favourites, its logs and
its activity history — lives in `%LOCALAPPDATA%\RepoDeck`.

Those are deliberately separate. **Uninstalling RepoDeck does not delete the second one.**
Programs RepoDeck installed on your behalf stay where they are, and if you reinstall
RepoDeck later it finds them again.

## What it does

- **Search in ordinary words.** "Edit videos", "music player", "send files" — or browse by
  category.
- **Explains what it found**, in plain English, rather than showing you a repository page and
  wishing you luck.
- **Tells you whether it will run on your computer**, and shows its reasoning. Every verdict
  has a **WHY?** beside it.
- **Installs what it safely can**, after showing you exactly what it will download, where it
  will put it, and what it will not do.
- **Keeps it working afterwards.** It checks for newer versions, shows you what an update
  would change, and swaps it in safely — your old copy is kept until the new one is proved to
  work. If an installation gets damaged, it can put it back.
- **Removes what it installed**, and only what it installed.

## What it will not do

- Run installers, scripts, or anything else it downloads
- Ask for administrator access
- Change Windows settings or touch anything outside its own folders
- Start a program until you ask it to

And the thing that matters more than any feature:

> RepoDeck cannot tell you whether software is safe or trustworthy. Nothing it shows you is a
> recommendation. It tells you what it found and how it worked it out, and the decision stays
> yours.

Stars are not treated as a quality signal, and "RepoDeck can install this" is a statement
about RepoDeck, not about the software.

## Known limitations

- **Windows only for now.** The code is cross-platform and RepoDeck has Linux paths built in,
  but it has never actually been run on Linux, so there is no Linux download.
- **Unsigned**, as above.
- **Not verified on a clean machine.** Everything was tested on a computer that already had
  developer tools installed. The build includes its own runtime and should not need anything,
  but "works on a fresh Windows install" has not been demonstrated. If you are running this on
  a clean machine, you are testing that for the first time — please say how it went.
- **GitHub rate limits.** Without a token you get 60 requests an hour and 10 searches a
  minute, which is easy to exhaust. Settings explains how to raise it.
- **Update checking costs one request per installed application**, one at a time, so a large
  library is slow to check.
- **Some projects cannot be compared.** When two release names cannot be honestly ordered,
  RepoDeck says it does not know rather than guessing. That is deliberate — guessing wrong
  would mean offering you an older version with the word "update" on the button — but it means
  some projects show "Can't determine" with no way to override it yet.
- **Downloads and Favorites are newer and less exercised** than the rest.

## Verifying your download

`RepoDeck-0.1.0-alpha-win-x64.sha256` contains SHA-256 checksums for both files.

```
sha256sum -c RepoDeck-0.1.0-alpha-win-x64.sha256
```

Or on Windows, in PowerShell:

```
Get-FileHash .\RepoDeck-Setup-0.1.0-alpha-win-x64.exe -Algorithm SHA256
```

## If something goes wrong

Settings shows which build you are running and has an **Open log folder** button. Including
the version and anything relevant from the log makes a problem much easier to track down.

The **What RepoDeck has done** list on the same page is a plain-English record of every
install, update, repair and removal — often enough on its own to explain what happened.
